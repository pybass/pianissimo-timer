# Rejected

Ideas we decided against, each with its reason. Do not propose one again unless its reason no longer holds.

- **Restore the bells after a phone restart.** A restart drops every alarm; the idea was a receiver for the boot
  that schedules them again from the saved state, and brings the notification back. Rejected: a restart is almost
  always a deliberate act, or a system update the user agreed to, and a timer of some minutes is almost never
  running at that moment. A restart cancels the bell, like Force stop; the app then opens idle, which it already
  does.
